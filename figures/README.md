## Generation

Figures will be generated by the analysis script:

```bash
python analyze_results.py --trials results/trials.jsonl --output-dir results/analysis
python generate_figures.py --analysis-dir results/analysis --output-dir figures/
```

## Style Guide

**Format**:
- Vector: PDF (for LaTeX inclusion)
- Raster: PNG at 300 DPI (for presentations)

**Color Scheme**:
- Reputation levels: Sequential (blues)
- Evidence levels: Diverging (red-yellow-green)
- Model families: Categorical (colorblind-safe palette)

**Typography**:
- Font: Times New Roman (academic standard) or Helvetica
- Title: 14pt
- Axis labels: 12pt
- Tick labels: 10pt

**Layout**:
- Single-column width: 3.5 inches
- Two-column width: 7 inches
- Margins: 0.25 inches minimum
